## 这一串做了什么（都验过）

1. **② 大图：拆掉 4MB 门槛，不是加缩图**。查 `dsh-attachment-local` 源码才发现归一化是 DSH 自己做的：
   源图准入 50MB / 像素 ≤6400 万，存前缩到 2048² 像素 / 长边 8192 / 目标 ≤4MB。插件的
   `RELAY_IMAGE_BYTES` 4MB 是内联 base64 时代的旧值，把手机照片直接挡回一行路径。改成 32MB。
2. **① 回顾窗引用**：`_bubble_menu(..., allow_quote=True, from_review=True)`；新增
   `_quote_choice()` —— 设 chip 后关回顾窗、主窗 lift + topmost、焦点进输入框。回顾窗是独立
   Toplevel 且同样 topmost，不关窗 chip 会被盖住；代价是回顾页滚动位置会丢。
3. 单测：`test/relay-image.test.mjs` 加「>4MB 也交给 saveImage」；`scripts/check-quote.py`
   加「回顾窗引用 → 关窗 + 主窗前置 + 焦点」。
4. 文档：README / 机制.md / 决策记录（新增 `.35` 一节）/ CHANGELOG 同步；任务书
   `docs/tasks/p2-followups.md`（可验收）。
