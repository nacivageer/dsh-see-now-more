- `_dialogs_topmost()` 把窗口登记进 `self._dlgs`；开关翻面时 `_follow_dialogs_topmost()` 统一改档
  （关 → `-topmost False`；开 → 进带 + 补一条 pin 链）。两个入口：设置页 `_apply_topmost`、
  手改配置后的看门狗 `_keep_on_top`（用 `want` 与 `_topmost_on` 的差异判过渡，只在过渡那一次动）。

  卡要跟着保持同一相对位置。

## 二、坑（都踩过，别再踩）

- **`selftest-ui.py` 的 `dialogs-topmost` 原来写死「弹窗必须在 topmost 带」**：`.44` 起弹窗跟随
  开关，关掉时它们本来就该退出带 —— 「关掉置顶 + 开着回顾窗」必假红（发 `.45` 时撞上）。
  现在期望值跟 `keepOnTop` 走：开 → 必须在带里，关 → 必须不在。
- **它还按 pid 数窗口**：搜狗输入法会往**前台进程**里注入 `SoPY_Status`（无标题、永远 topmost、
  我们管不着），按 pid 数就把别人的窗判成「没跟上开关」。现在只数类名以 `Tk` 开头的窗口。
- **它按「最大窗」选目标**：回顾窗开着时会被当成主窗 —— 用 `--hwnd 0x…` 指定。**这条没改**，
  下次想省事的话可以先判 `title == 'DSH'`。
- **`& "$env:USERPROFILE\.dsh\tools\git-push.ps1"` 会撞执行策略**：固定走
  `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <路径> …`（和 `note.ps1` 同一条路）。
- **`git commit --amend` 要重写 message**：这次拿上一笔的 msg 文件提交了一笔纯文档，只能再
  amend 一次；`--amend` 前先确认 message 讲的是这一笔的内容。
- **量 `chat.jsonl` 的成本要先确认 `W.CHAT_FILE` 指哪**：没设 `DSH_VIDEO_CACHE_DIR` 时它会落到
  `%LOCALAPPDATA%\dsh-video-storyboard\cache\chat.jsonl`（0 KB），第一次探针读的就是那个空的。
