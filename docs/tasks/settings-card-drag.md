## 为什么这样改

- **位置是「用户摆的」，不能被内容重排冲掉**：卡片高度会变（展开声音 / 朗读范围、阅读范围选项），
  重画是常态；把左上角记下来、只改尺寸，才符合「我把它拖到这儿了」的预期。
- **夹取按当下尺寸算，不是拖动那一刻**：卡片变高后底边可能出屏，重画时按新 `ch` 夹一次；
  顶 / 左边优先，右 / 下不够就往回挪。
- **松手也要夹**：以前拖出屏幕还能靠「改个选项就回默认」救回来；位置记住以后这条路没了，
  所以松手时夹一次，别让卡彻底点不到。
- **不跨打开保留**（`0.1.1-more.44` 的判断，**2026-11-27 晚推翻**）：当时的理由是「默认位置跟着
  主窗、中间偏上；主窗挪了还从上次拖动的位置弹出来会更怪」。补 `.45` 时格当场纠正了口径：
  要保留的是**设置页相对悬浮窗**的位置，不是屏幕绝对坐标。所以存的是相对偏移，窗挪到哪、
  卡跟着保持同一相对位置；夹取仍在 `_settings_paint` 里按当次尺寸兜底。

## 跨打开记住（`.45` 待发，2026-11-27 晚）

- 写法：`see-now.json` 的 `settingsCardOffset` = `[x - _x, y - _y]`（卡片左上角减悬浮窗左上角，
  **不是屏幕坐标**）。`_settings_drag_end` 松手时写**夹过的**那一对，且「拖回原处」也写
  （那也是一次「我就放这儿」）。
- 读法：`_open_settings` 用 `_settings_offset_saved()` 初始化 `st["off"]`（只认两个整数，坏值当没记过），
  `_settings_paint` 用 `self._x + dx, self._y + dy` 还原后再夹一遍 —— 那一刻才知道卡片高度。
- 验收：`check-settings-card.py` 的 `test_saved_offset` —— 记过 → 在主窗+偏移处；**主窗挪到
