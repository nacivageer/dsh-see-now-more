## 为什么这样改

- **位置是「用户摆的」，不能被内容重排冲掉**：卡片高度会变（展开声音 / 朗读范围、阅读范围选项），
  重画是常态；把左上角记下来、只改尺寸，才符合「我把它拖到这儿了」的预期。
- **夹取按当下尺寸算，不是拖动那一刻**：卡片变高后底边可能出屏，重画时按新 `ch` 夹一次；
  顶 / 左边优先，右 / 下不够就往回挪。
- **松手也要夹**：以前拖出屏幕还能靠「改个选项就回默认」救回来；位置记住以后这条路没了，
  所以松手时夹一次，别让卡彻底点不到。
- **不跨打开保留**：默认位置是「跟着主窗、中间偏上」。主窗挪了还从上次拖动的位置弹出来会更怪；
  关掉再开回到默认，符合现有经验（这次只修「改选项弹回去」）。
