## 二、坑（都踩过，别再踩）

- **Tk 的 `transient` 对 `overrideredirect` 的窗不设 owner**：正常 Toplevel `transient(root)` 后
  `GetWindow(GW_OWNER)` 等于主窗 HWND，override 的是 **0**；而且 master 没映射时 Tk 会压着
  窗口不 map（测试里 root withdraw 时弹窗永远不 map，ex 停在 0x4）。所以弹窗的 owner 只能自己设：
  `SetWindowLongPtrW(GWLP_HWNDPARENT)`（映射后 60ms）。探针与 `check-settings-card.py` 的
  `test_dialog_owner` 都走这条。
- **弹窗 topmost 必须走统一入口**：8 个 Toplevel 原来各自硬写 `attributes("-topmost", True)`，
  只改主窗不关它们，开关等于只做一半。源码守卫别删：`win.attributes("-topmost", True)` 一次都
  不该再出现。
- **设置卡位置是「用户摆的」**：`_settings_paint` 每次按主窗重算 x/y → 改一个选项就弹回默认。
  记住 `st["pos"]` 之外还要**松手夹回桌面**（位置一旦记住，拖出屏幕就再也点不到；旧行为靠
  「改选项回默认」兜住，修完这条路没了）。
- **设置卡最窄 456px 的旧文案早就在截断**：`模型能看屏幕（watch / peek / region 都可用）` 右缘
  467、重启提示右缘 517（Canvas 不折行不省略）。现在由 `check-settings-card.py` 按最窄档量 bbox
  守着；加行 / 改字先跑它。
- **`Out-File -Encoding utf8` 带 BOM**（PS 5.1）：拿它写 commit message 文件，`git commit -F` 会把
  U+FEFF 带进标题（`show` 里看得见那个方框）。今天踩过一次、`--amend` 修的。写 commit message
  用 python 的 `write_text(..., encoding="utf-8")`。
- **`git commit -- <未跟踪文件>` 不生效**：新文件先 `git add <路径>` 再 `commit -F <msg> -- <路径>`。
- **`node --test` 会跑两个新的 python check 包装测试**：它们要 Tk，没 Tk 的机器会 skip，
  别把 skip 当通过。
