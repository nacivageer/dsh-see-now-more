## 为什么现在做

缓冲解决「看什么」，四档解决「要不要打扰、打扰到什么程度」。

现在两件事都不对：**强命中一律叫醒**（贵一档，用户安静看片时被打断），**弱命中连记录都没有**
（事后无法回答「叫得对不对」）。四档是唯一能把代价真正分级、并且让「黑听 30 分钟」花 0 token
成为常态的办法。

## 四档（照机制文档，只补实现口径）

| 档 | 机制文档的条件 | 这一棒的实现口径 | 成本 |
|---|---|---|---|
| **警觉** | 弱命中（单惊叹词、无指代短问句） | 只记账：`lift.jsonl` 一行 + 进警觉池；**不取帧、不叫醒、不进窗** | 0 |
| **瞥**（默认） | 强命中（名字 / `你看这个` / `快看` / `卧槽` / `等一下`） | 按 `t0` 从缓冲取 1 帧 → PNG 落盘 → 窗内一行 meta → `lift.jsonl`；**不叫醒** | 0 token（帧只给人看） |
| **看** | 同一触发，但**最近 5 分钟有活跃对话** | 取 1 帧 + `wake()`；文案带时间码、那句台词、池子摘要（≤300 字）；模型可自己取帧 | 1 轮模型 |
| **追** | 只能由模型在「看」之后自己发起 | **插件不做**：模型自己调 `watch`。这里只保证 `lift.jsonl` 记到 `chase` | 用户/模型决定 |

**蓄水池**：5 分钟内「警觉」累计 ≥3 次、且这段时间没取过帧 → 自动升一次「瞥」，用**第 3 次**那条
的时间戳取帧（机制验收第 6 条）。升完把计数清零，免得攒着一直升。

**`lift.level` 是基线**：安静时按基线走；最近 5 分钟有活跃对话时自动升一档（`alarm → glance`、
`glance → look`、`look` 不变）。所以默认 `glance` = 安静时瞥、有人说话时看；设 `alarm` =
安静只记账、有人说话最多瞥一眼不叫醒。

**回落（`holdSec`，默认 15 秒，`0` = 关）**：从**最后一次语音/对话结束**起算，不是从抬头那一刻；
到点且**画面不动**才回「警觉」，回落后 `lift.jsonl` 记一条 `trigger:"hold"`。期间又有人说话，
计时从最后一句重来。

> 「画面不动」用**缓冲里最近两帧的像素差**判（采样几百个点，阈值 <0.5%）。**不能拿「没新台词」判**：
> 纯音乐/默片里静音但画面在动，那种情况回落就是错的。

## 这一棒的目标（三件可验收的事）

1. **判定**：强命中 → 瞥/看（按活跃对话与 `lift.level`）；弱命中 → 警觉；5 分钟 3 次警觉 → 升一次瞥。
2. **产物**：瞥 = 窗内一行 + 那一帧 PNG + `lift.jsonl`；看 = 叫醒文案带语境，模型能取到那一刻的帧。
3. **回落与账**：`holdSec` 到点回警觉；`status` 有当前档位与今日计数；`lift.enabled:false` 全关。

## 待你拍板

1. **`lift.level` 是基线还是天花板**（决定默认要不要叫醒）。
2. **瞥那一帧要不要落成 PNG**（落盘与「缓冲不落盘」是两件事，但会多一个目录）。
3. **「看」时模型怎么拿到帧**：新增 `see_now({action:"lift", since})`，还是只叫醒、让它自己 `watch`？
4. **「活跃对话」怎么判**：用户说过话 / 模型回合结束过，5 分钟窗口，还是只认前者？

**拍板结果（2026-11-10 22:2x，四条都按倾向）**：

1. **`lift.level` 是基线，有活跃对话自动升一档**。默认 `glance` → 安静时只「瞥」、有人说话时「看」；
   设成 `alarm` → 安静只记账，有人说话最多「瞥」一眼、不叫醒（这就是"最省模式"）。
   升档阶梯 `alarm → glance → look`，`look` 封顶；`chase` 不参与自动升。
2. **「瞥」那一帧落盘**：`~/.dsh/see-now/lift/<本地日期>/<毫秒>.png`（约 30–60 KB/张），
   保留 3 天、启动时顺手清更老的。这是验收第 7 条（窗里点开能看那一帧）唯一的做法。
3. **新增 `see_now({action:"lift", since})`**：`since` 是 epoch ms（就是台词 `t0`），返回那一刻的
   单帧图（低清档 ≈222 token）。缓冲里没有那一刻时**明确返回"没了"**，不拿当前帧顶。
4. **活跃对话 = 任一**：最近 5 分钟内**用户说过话**（loop 的 `lastUserAt`）**或模型上一回合结束过**
   （`~/.dsh/see-now/turn-state.json` 的 `endedAt`，index 已经在写）。两个信号取更晚的那个。

## 验收（缺一不算完）

1. **警觉不打扰**：只出弱命中的 10 分钟里，窗里一行都没有、模型一次没被叫、`lift.jsonl` 有行。
2. **瞥不叫醒**：安静看片时念「你看这个」→ 窗内出现一行（含时间与那句话）→ `lift.jsonl` 一条
   `level:"glance"` → **模型轮次计数不变**（对照：同一句在有对话时会被叫醒）。
3. **看得对**：有活跃对话时念「你看这个」→ 叫醒；文案里有时间码与那句台词；按 `t0` 取到的帧
   与台词偏差 ≤1 秒。
4. **蓄水池**：5 分钟内 3 声「啊？」→ 第 3 声后升一次「瞥」，取到的那一帧时间对得上第 3 声。
5. **画面没了就说没了**：触发句比 30 秒缓冲更早（比如 40 秒前）→ 只报文字 + 明说「那一刻的画面
   没了」，`lift.jsonl` 记 `frameAt:null`；**不许拿当前帧冒充**。
6. **回得去**：看之后 15 秒没人说话且画面不动 → 档位回「警觉」，`lift.jsonl` 一条 `trigger:"hold"`；
   这期间又有人说话 → 计时重置、不回。
7. **账记得住**：`status` 显示当前档位与「今日 警觉 N · 瞥 N · 看 N」，重启后不丢（从文件算）。
8. **最省档**：`lift.level:"alarm"` 时安静只记账；就算有活跃对话，最多升到「瞥」（取帧给人看、不叫醒），
   **永远不叫醒模型**。
9. **可关**：`lift.enabled:false` → 行为回到这一棒之前，`status` 里连档位行都没有。
10. `node --test` 全绿（现有用例一条不许挂），新增的判定/记账都有单测。

时延：机制目标是「≤2 秒」，P0 实测唤醒约 3 秒（含 ASR 断句 + 转写）。这一棒验收按 **≤3 秒**，
别把做不到的 2 秒写进验收。

## 不做（这一棒）

- **不做逐句模型判断**（机制明令）：每句台词调一次模型，与黑听省钱的初衷相反。
- **不让「追」自动进入**：`chase` 只能模型在「看」之后自己调 `watch`；插件不替它决定。
- **不改悬浮窗外观**：只多一行 `meta`，不加按钮、不加弹层。
- **不落警觉池全文**：`lift.jsonl` 只落**命中**（含警觉那一条），池子的其余内容留在内存。
- **不碰 `see-now` 仓**（那份 fork 只作参考实现）。

## 风险

- **误报比漏报贵**：瞥 = 一行 + 一帧（给人看），看 = 一轮模型。词表先窄后宽，宁漏勿滥。
- **「活跃对话」判错两个方向都疼**：该叫不叫（用户觉得它聋）／不该叫又叫（用户觉得它吵）。
  这个判据值得单独一组单测，别只靠手感。
- **`holdSec` 用「画面不动」判**：静止画面里光标一闪、视频暂停后字幕跳变都可能被当成「在动」，
  回落会晚；反过来纯黑场景两帧全等，回落会早。阈值要拿真素材标定一次（`scripts/` 里加个探针）。
- **瞥的 PNG 落盘**会留下可回看的画面文件 —— 与「缓冲不落盘」不冲突（缓冲是内存，瞥是用户要看的那一帧），
  但 **README 与 status 必须写清楚**，否则就是暗地里存图。
- **`lift.jsonl` 天天长**：按天切文件，顺手在 `status` 只读当天那份。
